# 2026-10-19 会话快照

今天围绕 pi-capsule-tools 做了一轮 UI 打磨，六个任务全部落地。

## 做了什么

1. **折叠行加耗时**：右对齐显示 `12ms` / `1.2s` / `1m05s`，取自 pi 渲染上下文的 `durationMs`。
2. **展开分两层**：`命令` 段给完整命令（头部那行是截断过的），`结果` 段给输出。
3. **恢复绿底**：`renderShell` 从 `self` 改回 `default`。pi 的外壳会用 `Box` + `toolSuccessBg`
   给整块上色；设成 self 把外壳连同底色一起绕过了。
4. **截断行底色修复**：`truncateToWidth` 在 `…` 前插完整 SGR 重置，把背景也清了。
5. **点击展开**：`tuiMode` 改 `fullscreen`。regular 模式的 `TuiMainScreen` 里没有任何鼠标解析代码。
6. **转轮换字形**：盲文 `⠋⠙⠹…` 在 Herdr 上走回退字体、宽度超一格，每 90ms 抖一次；改成 `◐◓◑◒`。

顺带做了一轮代码评审：展开态正文按宽度缓存换行（200 行输出渲染 2000 次 0.4ms）、
折叠态返回共享空组件、去掉重复的 `describe` 查找、把动画测试的等待从 3.1s 压到 2.1s。

## 实测结论

- **fullscreen 卡顿与胶囊无关**：用 pi 的 `renderLayoutFrame` 压测，2000 个折叠工具块每帧 0.56ms，
  60fps 预算 16.7ms，只占 4%。
- **`edit` 的 `+N -M` 计数正确**：pi 的 `details.diff` 不是标准 unified diff，没有文件头行，
  用真实 edit 工具跑纯新增/纯删除/多行替换三种都对。
- **双击胶囊出现两层**的隐患已排除：settings 里同时装了 npm 版和仓库版，已卸掉 npm 那份。
