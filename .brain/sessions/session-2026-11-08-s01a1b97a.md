# 会话：现在有个问题 ctx_execute 也要压缩一下，还有 现在think…

> 2026-11-08 · 技术类 · ctx_execute 进胶囊、think 默认折叠、热路径三处性能修复

## 出了什么问题
- `ctx_execute` 走 pi 默认渲染器，没进胶囊。
- think 整段铺开，不能自动折叠。
- 顺手审出三处热路径：`firstLine` split 整个 `code`；`edit` 每帧 split 整个 diff；展开结果行每帧 `new Capsule` 冲掉换行缓存。

## 怎么解决的
- `detailsOf` 加 `ctx_execute`；`hideThinkingBlock: true` 写进 `~/.pi/agent/settings.json`。
- `firstLine` 只看前 max+1 字符；折叠结果行早退；diff 计数按 `details` 引用缓存；展开 `Capsule` 按 `content` 数组复用。
- 装版切到本地路径 `../../Code/pi-capsule-tools`，卸掉 npm 旧版避免两层胶囊。

## 验证什么命令
```bash
npm run check        # 全绿
npm run typecheck    # 无错
```
用户重启后确认：ctx_execute 是一行胶囊；think 只剩 Thinking... 可点开。
